## ✨ 特性

监控撤回行为。支持对`文字`、`图片`、`视频`、`文件`、`聊天记录`、`小程序`消息的撤回行为进行“恢复”

## ⚙️ 插件配置

首次加载后，请在 `AstrBot 后台` -> `插件页面` 找到本插件进行设置
